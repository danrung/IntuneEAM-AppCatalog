Detection expects a newer version than the catalog lists50

These detection rules require a version at or above a threshold that is higher than the version the catalog lists. Sometimes the file just numbers its versions differently. Otherwise either the installer is newer than the catalog says, or a device that installs exactly the listed version is never detected and Intune reports the installation as failed. Worth a test deployment before relying on it.
