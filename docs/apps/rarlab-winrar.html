Rarlab WinRAR

by Rarlab

WinRAR provides the full RAR and ZIP file support, can decompress CAB, GZIP and other archive formats

Rarlab WinRAR is published in the Microsoft Intune Enterprise App Management (EAM) catalog, so Intune can deploy and update it on Windows devices without a repackaged installer. It has been in the catalog since at least 7 Dec 2025, the first export on record. 17 version updates have been recorded since, roughly one every 6 days; the latest, on 14 Jul 2026, moved 7.22 → 7.23.

How to deploy this from Intune
  1. In the Microsoft Intune admin center, go to Apps › All apps › Create.
  2. Choose the Enterprise App Catalog app type, then search the catalog for Rarlab WinRAR.
  3. Pick the package whose branch, version, architecture and locale you need — the table above lists every one Microsoft publishes.
  4. Finish the app information and assignment steps. Where auto-update is supported, Intune keeps the app current on its own.

Microsoft's own documentation: Enterprise App Management in Intune.
