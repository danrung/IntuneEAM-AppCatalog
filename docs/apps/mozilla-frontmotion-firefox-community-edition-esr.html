Mozilla FrontMotion Firefox Community Edition ESR

by Mozilla

Get Firefox, a free web browser backed by Mozilla, a non-profit dedicated to internet health and privacy. Available now on Windows, Mac, Linux, Android and iOS.

It has been in the catalog since at least 7 Dec 2025, the first export on record. No new version has been published to it since.

How to deploy this from Intune
  1. In the Microsoft Intune admin center, go to Apps › All apps › Create.
  2. Choose the Enterprise App Catalog app type, then search the catalog for Mozilla FrontMotion Firefox Community Edition ESR.
  3. Pick the package whose branch, version, architecture and locale you need — the table above lists every one Microsoft publishes.
  4. Finish the app information and assignment steps. Where auto-update is supported, Intune keeps the app current on its own.

Microsoft's own documentation: Enterprise App Management in Intune.
