Microsoft OLE DB Driver 18 for SQL Server

by Microsoft

OLE DB Driver for SQL Server was designed to provide a simplified method of gaining native data access to SQL Server using OLE DB. It provides a way to innovate and evolve new data access features without changing the current Windows DAC components, which are now part of the Microsoft Windows platform.

Microsoft OLE DB Driver 18 for SQL Server is published in the Microsoft Intune Enterprise App Management (EAM) catalog, so Intune can deploy and update it on Windows devices without a repackaged installer. It has been in the catalog since at least 7 Dec 2025, the first export on record. One version update has been recorded since, on 12 Oct 2026, moving 18.7.5 → 18.7.6.
