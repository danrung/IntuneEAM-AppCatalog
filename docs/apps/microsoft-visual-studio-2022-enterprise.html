How to deploy this from Intune
  1. In the Microsoft Intune admin center, go to Apps › All apps › Create.
  2. Choose the Enterprise App Catalog app type, then search the catalog for Microsoft Visual Studio 2022 Enterprise.
  3. Pick the package whose branch, version, architecture and locale you need — the table above lists every one Microsoft publishes.
  4. Finish the app information and assignment steps. Where auto-update is supported, Intune keeps the app current on its own.
