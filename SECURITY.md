# Security Policy

## Scope

This repository contains public catalog data exported from the Microsoft Graph API, a Python script that turns it into documentation, and a static website. It does not process user data, hold credentials, or run any server-side code.

The PowerShell script generated by the EAM Quickstart on [eam.drung.dev](https://eam.drung.dev/) runs entirely in your own tenant with your own permissions. Review it before running it, and use `-WhatIf` first.

## Reporting a vulnerability

If you find a security issue in the generator script, the workflow, the website, or the Quickstart script, please report it privately rather than opening a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/danrung/IntuneEAM-AppCatalog/security/advisories/new) for this repository

You can expect an acknowledgement within a few days. Once the issue is understood and fixed, it will be documented in the release notes.

## Out of scope

- Issues in the Microsoft Intune service or the Graph API itself. Please report those to Microsoft through the [MSRC](https://msrc.microsoft.com/report/vulnerability).
- Vulnerabilities in third-party applications listed in the catalog. The catalog only records what is available; it does not distribute the software.
